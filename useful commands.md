# Useful ChatGPT Commands

> **Important:** Commands such as `/explain` and `/examples` are reusable prompt shortcuts, not guaranteed built-in ChatGPT slash commands. Type the command and your topic in the same message. You can also give the instruction naturally without a slash command.

## 1. Learning and Understanding

| Command | Purpose | Example |
|---|---|---|
| `/explain` | Explain a topic in simple language. | `/explain Java interfaces in simple Hindi with examples.` |
| `/eli5` | Explain as if I were five years old. | `/eli5 How does a Jenkins webhook work?` |
| `/examples` | Give practical examples. | `/examples Give three Selenium examples.` |
| `/deepdive` | Explain a topic in depth. | `/deepdive Explain Java collections.` |
| `/stepbystep` | Teach one step at a time. | `/stepbystep Help me set up Jenkins.` |
| `/analogy` | Explain using a real-life analogy. | `/analogy Explain a Jenkins pipeline.` |
| `/compare` | Compare two concepts in a table. | `/compare Selenium and Playwright.` |
| `/difference` | Explain differences between two things. | `/difference Explain `GET` vs `POST` requests.` |
| `/why` | Explain why something happens. | `/why does my browser close after a Selenium test?` |
| `/how` | Explain how something works. | `/how does GitHub trigger Jenkins?` |
| `/summary` | Summarize a topic into key points. | `/summary Summarize Java inheritance.` |
| `/simplify` | Rewrite a complex explanation in simple words. | `/simplify Explain this technical paragraph.` |

## 8. Reusable Master Command: `/learn`

Copy and reuse this prompt for any topic:

```text
/learn

Teach me [TOPIC] in simple Hindi.

1. Explain the concept from beginner level.
2. Explain each important line of code.
3. Give practical examples.
4. Explain common mistakes and how to fix them.
5. Show real-world project usage.
6. Provide interview questions and answers.
7. End with a short quiz.
8. Wait for my response before moving to the next lesson.

Do not skip steps or assume I already understand the basics.
```

## Quick Tip

You do not need to memorize these labels. A natural-language instruction works too. For example:

> Explain this code line by line in simple Hindi, give practical examples, and quiz me at the end.

That instruction works without `/explaincode`.
